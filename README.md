# ccblog - Claude Code to GitHub Gist

A simple CLI tool to create GitHub gists from your Claude Code conversation transcripts.

## What It Does

Interactively select a Claude Code project and conversation, then instantly create a public GitHub gist to share your transcript.

```
~/.claude/projects/your-project/*.jsonl → GitHub Gist
```

## Prerequisites

- [Bun](https://bun.sh/) runtime
- [GitHub CLI (`gh`)](https://cli.github.com/) installed and authenticated

## Setup

```bash
# Install dependencies
bun install

# Make sure gh CLI is authenticated
gh auth status
```

## Usage

### Option 1: Run with Bun (Recommended for Development)

```bash
bun ccblog.ts
```

### Option 2: Build Standalone Executable (For Sharing)

**Read these docs in order:**

1. **[PROJECT.md](./PROJECT.md)** - Core concept (5 min read)
2. **[MILESTONES.md](./MILESTONES.md)** - 8 milestones to build independently
3. **[PROGRESS.md](./PROGRESS.md)** - Track what's done

**Quick Start:**

```bash
# Build for your platform
bun run build:ccblog

# Run the compiled binary
./ccblog
```

Pick a milestone from `MILESTONES.md`, claim it in `PROGRESS.md`, and build it.

The tool will guide you through:

1. **Select a project** from your `~/.claude/projects` directory
2. **Select a conversation** (shows Claude's summary or first user message)
3. **Create a secret gist** automatically with the conversation content

## Features

- 🎯 Interactive project and conversation selection
- 💬 Shows conversation summaries (generated by Claude) or first user message
- 📅 Conversations sorted by modification time (most recent first)
- 📊 Shows file sizes and session counts
- 🔒 Automatically creates **secret** (private) gists
- ⚡ Fast and lightweight (powered by Bun)
